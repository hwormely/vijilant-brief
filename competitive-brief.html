The Recovery Score Ring.
Our signature differentiator.

The Recovery Score Ring is the signature visual element of Vijilant — a 0–1000 score ring that appears on every client record. Compact size (36px) in list views; large size (72px) in the client header. Score is computed server-side from the 5-domain assessment and updates automatically. Never manually entered, adjusted, or overridden at any role level. A ? icon on every ring opens a domain-level explainer popover.

Triage that updates itself

Every time a case note is saved, a task is completed, or a referral outcome is logged, the Auto-Triage Engine re-evaluates the client's tier. Critical cases don't stay buried in a flat list — they surface automatically.

AI-written rationale

The system doesn't just assign a tier — it writes the rationale. Assessment Part B is generated automatically on save: official Triage Tier (T1–T4), Recovery Score (0–1000), and a plain-language explanation of why. CMs read it. They don't write it.

Recovery Plan generated on save

When a 12-section assessment is completed, the system computes a Recovery Score (0–1000) and generates a full, personalized Recovery Plan — Housing, Financial, Health, Legal, Emotional — without the CM drafting a single line.

HIPAA-grade from the ground up

HIPAA-certified infrastructure with enterprise BAA. Every write to a client record is logged in a full audit trail before any PHI enters the system. Biometric auth enforced. Analytics self-hosted within Vijilant's infrastructure — zero PHI touches a third party.

Where we're
still building.

Vijilant is purpose-built and field-tested in concept — but v1 is the beginning. These are real gaps we're closing methodically, not afterthoughts.

No production deployment at scale yet

Vijilant is in active development and currently validated against LLP's real caseload context. First production deployment is the LLP pilot. RecoverPrepared has more field time — that matters and we respect it.

AI rationale is only as good as the assessment input

The Auto-Triage Engine relies on the quality and completeness of assessment data entered by CMs. Incomplete assessments produce lower-confidence triage outputs. This is disclosed in the system and surfaced in the UI.

Enterprise multi-org configurability is phase 2

The architecture supports multi-tenancy from day one. Phase 2 lets any DCM organization configure Vijilant to its own program without a services engagement: import an aid partner's existing application form and Vijilant auto-builds the template. The option entry-points already ship in the app; the parsing and per-org configuration engines are the post-LLP-pilot build.

Survivor portal is live but early

The survivor portal shipped with v1 core features: recovery ring, recovery plan, aid applications, messaging, document upload, and application signature. Full consent and security infrastructure for broader public access is a post-pilot build.
